# NvpwrControl Binary Drop Folder

Place the extracted files from upstream **`nvidia-power-control`** (`NvpwrControl`) in this directory (`nvpwr/`):

- `NvpwrControl.exe`
- `NvpwrCtl.exe`
- `Nvpwr.sys`
- `Nvpwr.cer`

Download from upstream:
- Repository: <https://github.com/timmyy123/nvidia-power-control>
- Releases / site: <https://www.nvpwrcontrol.site> *(for NVIDIA driver `616.92`, `NvpwrControl v1.8.0` was used; check `timmyy123/nvidia-power-control` for newer driver builds)*

> **Note:** Third-party binaries are intentionally excluded from this repository. All automation scripts in `../scripts/` look in this folder (`../nvpwr/`) automatically.
